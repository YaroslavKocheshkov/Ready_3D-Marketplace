Materials

The basic building blocks of surface appearance

01

Principled PBR

The main shader used to create realistic materials in Blender.

USE CASE

Most everyday materials

IMPORTANT MAPS

Base Color · Metallic · Roughness · Normal

02

HANDPAINT

Hand-painted material created by hand, primarily using a graphics tablet.

USE CASE

Cartoons, stylized and low-poly games

IMPORTANT MAPS

Base Color · Roughness · Normal

03

SMART MATERIAL

Automatically creates a complete material setup using procedural textures and shaders, making it easier to create detailed surfaces

USE CASE

Quickly creating detailed materials

EXAMPLES

Metal · Wood · Plastic · Fabric · Stone

Texture Maps

The main texture maps used to control the appearance and physical properties of materials.

01

BASE COLOR

Defines the main visible color of the material. It contains the basic color information of the surface.

CONTROLS

Surface Color

COMMON USE

Wood · Metal · Fabric · Plastic · Stone

02

ROUGHNESS

Controls how rough or smooth a surface appears. It determines how strongly light is scattered across the material.

LOW VALUE

Smooth · Glossy · Reflective

HIGH VALUE

Rough · Matte · Diffuse

03

METALLIC

Controls whether the material behaves like a metal or a non-metal surface.

VALUE 0

Non-metal · Plastic · Wood · Stone

VALUE 1

Metal · Steel · Aluminum · Gold

04

NORMAL

Simulates small surface details by changing how light interacts with the surface without significantly changing the geometry.

CONTROLS

Surface normals and small details

COMMON USE

Scratches · Panels · Fabric · Concrete · Bricks
