BLENDER CHEATSHEET

Render

A quick reference for Blender rendering settings

← Back to Learning
01

Render Engine

Determines how Blender calculates the final image. Choose between real-time and physically based rendering.

OPTIONS

Cycles · Eevee

USE CASE

Final image rendering

02

Samples

Controls how many samples are used to calculate the rendered image. Higher values usually reduce noise but increase render time.

LOW

Fast preview

HIGH

Better quality

03

Resolution

Defines the width and height of the final rendered image.

RESOLUTION

480p vs 4k

USE CASE

Image and animation output

04

Lighting

Controls how light interacts with objects and creates the overall mood of the scene.

MAIN TYPES

Point · Area · Sun

USE CASE

Scene illumination

05

Denoising

Reduces visible noise in rendered images, allowing you to use fewer samples.

USE CASE

Cleaner renders

BENEFIT

Faster rendering

06

Output

Defines where and how Blender saves the final rendered image or animation.

FORMATS

PNG · JPEG · EXR

USE CASE

Save final render
