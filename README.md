# Ready_3D-Marketplace

PolyMarket is a marketplace website for selling 3D assets, including models, materials, environments, and textures. The project was developed using HTML, CSS, and JavaScript as part of a web development course.

# Features
Product catalog with dedicated category pages: 3D Models, Materials, Environments, and Textures.
Ready-to-use page layouts and product card templates, allowing new sections and products to be added quickly while maintaining a consistent design.
Payment system: the entire purchasing process is implemented; only integration with a payment service provider remains.
Clean and user-friendly interface with intuitive navigation and search functionality.
Animations and 3D elements that bring the website to life.
