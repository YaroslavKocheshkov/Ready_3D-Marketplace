PolyMarket — 3D Asset Marketplace

PolyMarket is an online marketplace for selling 3D assets, including models, materials, environments, and textures. The project was built using HTML, CSS, and JavaScript as part of a web development course.

Features
Product catalog with dedicated category pages: 3D Models, Materials, Environments, and Textures
Ready-made page and product card templates — new sections and products can be added quickly while maintaining a consistent design
Payment system: the entire purchasing process is implemented; only a payment provider integration remains
Simple and user-friendly interface with convenient navigation and search
Animations and 3D elements that bring the website to life
Technologies
HTML5
CSS3
JavaScript
Git 

Future Improvements
Integration with a payment provider to process transactions
Expansion of the product catalog
